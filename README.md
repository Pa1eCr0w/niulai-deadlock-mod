## 文件结构与制作

- `dist/`：与当前安装一致的管理器 ZIP。
- `compiled/`：最终 VPK 的 26 个资源。
- `source/authoring/`：初始、表情绑定及游戏导出阶段 Blender 文件。
- `source/models/`、`source/materials/`：FBX、ModelDoc、材质及贴图。
- `source/ui/`：最终独立艺术字 XML/CSS/JS/SVG。
- `source/scripts/`：历史制作脚本，路径已替换为 `./workspace/`；需按本机 Blender/Source 2 工具链配置，不是无人值守一键模型编译器。
- `art/installed/`：实际安装美术解码稿。
- `art/archive/`：包含被替代版本的美术历史档案；其中 `current` 是档案整理时分类，最终安装内容以 `compiled` 和 `dist` 为准。
- `validation/`：资源哈希与艺术字对照。

运行 `python3 tools/build_vpk.py` 可从最终编译资源确定性重建 VPK，输出到 `build/`。源码重新编译需要匹配的 Deadlock/Source 2 工具链，未声称已在干净机器验证完整源码构建。
